# Data Visualisatie Prototype Game

Een Unity-gebaseerd prototype dat is ontwikkeld om data‐visualisatie in een gameomgeving te verkennen. Het combineert visuele weergave, mogelijk shaders, en spelachtige interactie om data op een intuïtieve manier zichtbaar te maken.

## Over

Dit project is een prototype game/omgeving gebouwd met Unity (C#, ShaderLab, enz.) om verschillende data‐visualisatietechnieken te testen. Het is bedoeld om te onderzoeken hoe data op een interactieve manier visueel kan worden weergegeven, eventueel met behulp van shaders en game‐achtige elementen.

---

## Functies

- Visualisatie van data via Unity’s rendering pipeline en shaders.  
- Interactieve omgeving: visualisaties reageren op invoer van de gebruiker en spelmechanieken.  
- Shader-effecten voor esthetische of prestatie-experimenten (ShaderLab / HLSL).  
- Modulaire structuur, waardoor eenvoudig nieuwe visualisaties kunnen worden toegevoegd.
